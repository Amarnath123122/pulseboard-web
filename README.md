# pulseboard-web

The Angular 17 monorepo website: the pulseboard app plus the data-access library (API and auth clients, token refresh, WebSocket).

**Everything about Pulseboard (architecture, how to run, deploy, test, troubleshoot and the evidence it works) is in one guide:**

➡️ **[pulseboard-platform/README.md](https://github.com/Amarnath123122/pulseboard-platform#readme)**

## Quick start for this repo
```
npm install
npm start          # http://localhost:5173 (dev proxy = gateway to identity :8100 and api :8000)
npm run build
```
